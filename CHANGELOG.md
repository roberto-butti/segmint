# Changelog

Notable changes to Segmint are documented in this file.

## [0.99.0] - WIP

Initial pre-release of Segmint.

- Collect page views, campaign data, referrers, and custom events through the API and
  JavaScript SDK.
- Evaluate visitors against configurable audience-segment rules in real time.
- Suggest useful segments automatically from collected event data.
- Define reusable rule templates and copy segments or templates across projects.
- Inspect project activity, visitor events, segment matches, and audience distribution.
- Test hypothetical events without storing them using dry-run evaluation.
- Integrate segment results into frontend applications and CMS-driven content.
- Organize projects within organizations using owner, admin, member, and guest roles.
- Invite organization members by email and assign guests to specific projects.
- Create, revoke, reactivate, and rotate project access tokens.
- Provide organization-aware dashboards, navigation, favorite projects, and contextual
  setup guidance.
- Include documentation for the API, JavaScript SDK, data model, architectural decisions,
  and coding-agent-assisted frontend integration.
